A página de apresentação não exige cadastro. Cadastro e login ficam nos aplicativos. Confirmação de e-mail obrigatória; configuração do envio público de e-mails ainda pendente.







O pacote web usado na publicação tem SHA-256 fixado no workflow. Somente arquivos públicos são publicados; segredos dos serviços ficam no backend. O histórico de chats ainda não tem criptografia ponta a ponta. Consulte as notas da versão para limitações e validação.




Windows e Web: beta **1.0.0**. Android ARM64 permanece em **0.9.0**, enquanto a atualização compatível é preparada.

Clientes antigos não informam sua plataforma ao consultar o feed. O campo legado `version` permanece em `0.9.0`, para evitar oferecer um APK Android inexistente; as versões por plataforma estão em `platforms`.
